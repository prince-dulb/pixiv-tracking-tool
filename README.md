# Pixiv Tracking Tool

自动监控 Pixiv 特别关注画师的新作品，无条件下载全部插画/漫画/动图，从此不再痛失最喜爱的画师的被删除作品，在有大量关注的情况下也能不错过特别关注画师的新作。

## 快速开始

1. 双击 `PixivTracker_vX.X.X.exe` 启动
2. 首次启动会自动弹出浏览器，登录你的 Pixiv 账号完成授权
3. 浏览器登录成功后确认授权
4. 打开 http://localhost:8000 进入 Web 界面
5. 手机也可以访问[你的电脑IP]:8000 进入 Web 界面

## 使用方法

### 添加画师
- 进入「画师管理」页面
- 搜索画师名称或直接输入 Pixiv 用户 ID（如 `12345678`）
- 点击「特别关注」，系统会自动拉取该画师的全部已有作品并下载

### 浏览作品
- 首页显示全部已下载作品，可按画师和类型筛选
- 点击作品缩略图查看详情

### 定时检查
- 默认每 6 小时自动检查关注画师是否有新作品
- 可在「设置」页面手动触发检查

## 数据存储

所有数据存放在数据目录下（默认程序所在目录），结构如下：

```
数据目录/
├── data/              数据库和认证 token
├── images/            下载的作品图片
│   ├── 画师名 12345/
│   └── 画师名 67890/
└── .env               配置文件
```

在「设置」页面可修改数据存储目录，修改时自动迁移已有数据。

## 配置文件 (.env)

```env
# 服务端口
HOST=0.0.0.0
PORT=8000

# 数据存储目录（默认 . 即程序所在目录）
# DATA_ROOT=.

# 定时检查间隔
CHECK_INTERVAL_HOURS=6
```

## 系统要求

- Windows 10+
- 能访问 Pixiv 的网络环境

## 注意事项

- 作品下载到本地后，即使画师在 Pixiv 上删除作品，本地仍有备份
- Ugoira（动图）会自动转换为 GIF 格式
- 多页作品（漫画）会下载所有页面
